## 1. Завдання попередньої підготовки (Prerequisite Tasks)

### Відповіді на питання (Answers to Questions):

#### 1.1. Purpose of AMIs and Differences Between Private and Public AMIs
* **Purpose of AMI (Amazon Machine Image):** An AMI is a master image/template that provides the information required to launch an EC2 instance. It includes an operating system (Linux, Windows, macOS), an application server, pre-installed software applications, and initial configuration settings.
* **Public vs. Private AMIs:**
  * **Public AMIs:** Published by AWS (Official AMIs) or shared by the community (AWS Marketplace) for general public usage.
  * **Private AMIs:** Custom images created by a specific AWS user/organization for their internal use, containing proprietary applications or specific system configurations.

#### 1.2. Purpose of EBS and Supported EBS Volume Types in AWS
* **Purpose of EBS (Elastic Block Store):** EBS provides persistent, high-performance block-level storage volumes for use with Amazon EC2 instances. Unlike ephemeral instance store volumes, data stored on EBS persists independently of the instance lifecycle.
* **Supported EBS Types:**
  * **General Purpose SSD (`gp2` / `gp3`):** Balanced price-performance volume suitable for broad workloads, OS boot volumes, and dev/test environments.
  * **Provisioned IOPS SSD (`io1` / `io2`):** Highest performance volumes for mission-critical, low-latency databases.
  * **Throughput Optimized HDD (`st1`):** Low-cost storage designed for frequently accessed, throughput-intensive workloads.
  * **Cold HDD (`sc1`):** Lowest-cost block storage for infrequently accessed data.

#### 1.3. Purpose of Snapshots
* **Purpose:** EBS Snapshots are point-in-time incremental backups of EBS volumes stored durably in Amazon S3. They are used for data redundancy, disaster recovery, volume cloning, and creating custom AMIs.

#### 1.4. Core Instance Types in AWS and Their Use Cases
1. **General Purpose (`t2`, `t3`, `m5`):** Balanced compute, memory, and networking resources. Ideal for web servers, code repositories, and small databases.
2. **Compute Optimized (`c5`, `c6g`):** High ratio of vCPUs to memory. Ideal for compute-intensive applications and high-performance web servers.
3. **Memory Optimized (`r5`, `x1`):** High memory capacity. Ideal for in-memory databases (e.g., Redis) and real-time big data analytics.
4. **Accelerated Computing (`p4`, `g4`):** Equipped with hardware GPUs. Ideal for Machine Learning and 3D simulations.
5. **Storage Optimized (`i3`, `d2`):** High sequential read/write capabilities for large local datasets.

#### 1.5. Free Tier Supported OS AMIs (Windows / Linux / macOS)
* **Linux (Ubuntu Server 24.04 LTS / Amazon Linux 2023):** Configured for x86_64 or ARM architectures. Supported under Free Tier (`t2.micro`/`t3.micro`).
* **Windows (Windows Server 2025 / 2022 Base):** Requires at least 30 GB EBS boot disk. Pre-configured with RDP support on port 3389. Supported under Free Tier (`t2.micro`).
* **macOS (macOS Sonoma / Ventura):** Dedicated Physical Mac mini hosts. **Not** eligible for AWS Free Tier.

## 3. Контрольні питання (Review Questions)

### 3.1. What role does a Key Pair play when connecting to an EC2 instance?
A **Key Pair** consists of a Public Key (stored by AWS on the instance) and a Private Key (stored locally by the user). It uses asymmetric cryptography to authenticate SSH connections (Linux) or decrypt the Administrator password (Windows).

### 3.2. Which command is used to connect to an EC2 instance via SSH?
`ssh -i /path/to/private-key.pem username@public-ip-address`  
*Example:* `ssh -i "linux-key.pem" ubuntu@54.93.120.45`

### 3.3. How can you connect to an AWS EC2 Linux instance?
1. **SSH (Secure Shell):** Direct terminal access using key pairs via port 22.
2. **EC2 Instance Connect:** Browser-based SSH connection directly in the AWS Console.
3. **AWS Systems Manager Session Manager:** Secure CLI access without opening inbound port 22.

### 3.4. How can you connect to an AWS EC2 Windows instance?
1. **RDP (Remote Desktop Protocol):** Connect using a GUI client (`mstsc`) via port 3389 after decrypting the password.
2. **Fleet Manager / AWS Systems Manager:** Browser-based desktop session in the console.

### 3.5. What is the difference between Stop and Terminate states for an EC2 instance?
* **Stop:** Equivalent to powering down. EBS volumes and configurations are preserved. Compute charges pause, storage charges remain. Can be restarted.
* **Terminate:** Permanent deletion of the instance and its attached root EBS volume. IPs are released. Cannot be recovered.
