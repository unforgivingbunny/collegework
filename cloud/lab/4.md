## 1. Завдання попередньої підготовки (Prerequisite Tasks)

### Відповіді на питання (Answers to Questions):

#### 1.1. Purpose of AMIs and Differences Between Private and Public AMIs
- **Purpose of AMI (Amazon Machine Image):** An AMI is a master image/template that provides the information required to launch an EC2 instance. It includes an operating system (Linux, Windows, macOS), an application server, pre-installed software applications, and initial configuration settings.
- **Public vs. Private AMIs:**
  - **Public AMIs:** Published by AWS (Official AMIs) or shared by the community (AWS Marketplace) for general public usage.
  - **Private AMIs:** Custom images created by a specific AWS user/organization for their internal use, containing proprietary applications or specific system configurations. Access can be shared explicitly with selected AWS Account IDs.

#### 1.2. Purpose of EBS and Supported EBS Volume Types in AWS
- **Purpose of EBS (Elastic Block Store):** EBS provides persistent, high-performance block-level storage volumes for use with Amazon EC2 instances. Unlike ephemeral instance store volumes, data stored on EBS persists independently of the instance lifecycle.
- **Supported EBS Types:**
  - **General Purpose SSD (`gp2` / `gp3`):** Balanced price-performance volume suitable for broad workloads, OS boot volumes, and dev/test environments.
  - **Provisioned IOPS SSD (`io1` / `io2`):** Highest performance volumes for mission-critical, low-latency databases (e.g., MongoDB, PostgreSQL, Oracle).
  - **Throughput Optimized HDD (`st1`):** Low-cost storage designed for frequently accessed, throughput-intensive workloads (Big Data, Data Warehouses).
  - **Cold HDD (`sc1`):** Lowest-cost block storage for infrequently accessed data (large log files, backups).

#### 1.3. Purpose of Snapshots
- **Purpose:** EBS Snapshots are point-in-time incremental backups of EBS volumes stored durable in Amazon S3. They are used for data redundancy, disaster recovery, volume cloning, and creating custom AMIs. Incremental backup means only the blocks changed since the last snapshot are saved.

#### 1.4. Core Instance Types in AWS and Their Use Cases
1. **General Purpose (`t2`, `t3`, `m5`):** Balanced compute, memory, and networking resources. Ideal for web servers, code repositories, and small databases.
2. **Compute Optimized (`c5`, `c6g`):** High ratio of vCPUs to memory. Ideal for compute-intensive applications, high-performance web servers, scientific modeling, and batch processing.
3. **Memory Optimized (`r5`, `x1`):** High memory capacity. Ideal for in-memory databases (e.g., Redis, SAP HANA) and real-time big data analytics.
4. **Accelerated Computing (`p4`, `g4`):** Equipped with hardware GPUs. Ideal for Machine Learning, AI model training, graphics rendering, and 3D simulations.
5. **Storage Optimized (`i3`, `d2`):** High sequential read/write capabilities for large local datasets. Ideal for NoSQL databases and data warehousing.

#### 1.5. Free Tier Supported OS AMIs (Windows / Linux / macOS)
- **Linux (e.g., Ubuntu Server 24.04 LTS / Amazon Linux 2023):**
  - *Hardware/Software:* Configured for x86_64 or ARM (Graviton) architectures. Runs lightweight kernel with systemd, SSH enabled on port 22, and package managers (`apt`/`dnf`). Supported under Free Tier (`t2.micro`/`t3.micro`).
- **Windows (e.g., Windows Server 2025 / 2022 Base):**
  - *Hardware/Software:* Requires at least 30 GB EBS boot disk. Pre-configured with Remote Desktop Protocol (RDP) on port 3389, PowerShell, and WinRM support. Supported under Free Tier (`t2.micro`).
- **macOS (e.g., macOS Sonoma / Ventura):**
  - *Hardware/Software:* Dedicated Physical Mac mini hosts (Intel or Apple Silicon M1/M2 chips). Designed for iOS/macOS application development. **Note:** macOS instances are **NOT** eligible for the AWS Free Tier (require minimum 24-hour dedicated host allocation).

## 3. Контрольні питання (Review Questions)

### 3.1. What role does a Key Pair play when connecting to an EC2 instance?
A **Key Pair** consists of a Public Key (stored by AWS on the EC2 instance) and a Private Key (stored locally by the user, e.g., `.pem` or `.ppk` file). It uses asymmetric cryptography to securely authenticate the identity of the client connecting via SSH (Linux) or decrypting the initial Administrator password (Windows) without sending sensitive passwords over the network.

### 3.2. Which command is used to connect to an EC2 instance via SSH?
The standard OpenSSH command syntax is:
```bash
ssh -i /path/to/private-key.pem username@public-ip-address
```
*Example:* `ssh -i "linux-key.pem" ubuntu@54.93.120.45`

### 3.3. How can you connect to an AWS EC2 Linux instance?
1. **SSH (Secure Shell):** Direct CLI terminal access using SSH key pairs via port 22.
2. **EC2 Instance Connect:** Browser-based SSH connection managed directly within the AWS Console.
3. **AWS Systems Manager (SSM) Session Manager:** Secure CLI access without opening inbound port 22 in Security Groups or requiring a public IP.

### 3.4. How can you connect to an AWS EC2 Windows instance?
1. **RDP (Remote Desktop Protocol):** Connect using a GUI client (e.g., Windows `mstsc`, Microsoft Remote Desktop on macOS) via port 3389 after decrypting the default Administrator password using the private key.
2. **Fleet Manager / AWS Systems Manager:** Browser-based full desktop RDP session directly inside the AWS Management Console.

### 3.5. What is the difference between Stop and Terminate states for an EC2 instance?
- **Stop (Stopping/Stopped):**
  - Equivalent to powering down a physical server.
  - The instance retains its attached EBS volumes, configuration, and Private IP address.
  - Compute hourly charges pause, but EBS storage costs remain active.
  - The instance can be restarted at any time.
- **Terminate (Shutting-down/Terminated):**
  - Equivalent to deleting/destroying the server permanently.
  - Attached root EBS volumes are deleted by default (unless `DeleteOnTermination=false` was configured).
  - All allocated public/private IP addresses are released back to AWS.
  - The instance cannot be recovered or restarted once terminated.
