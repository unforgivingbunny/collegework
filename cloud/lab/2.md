### Перспективні напрямки розвитку AWS, Azure та GCP

**AWS (інновації останніх років):**

AWS зосередилася на створенні **Agentic AI** — автономних AI-агентів, які працюють без людини. На re:Invent 2025 було представлено **Frontier Agents** — агентів, що здатні працювати годинами й днями без втручання людини, виконуючи складні завдання. Також запущено **Trainium3 UltraServers** — 3-нм AI-чипи, що забезпечують 4.4x продуктивності та 4x енергоефективності порівняно з попереднім поколінням. **AWS Graviton5** — власний CPU з 192 ядрами та 5x більшим кешем. **AWS AI Factories** дозволяють клієнтам перетворити існуючу інфраструктуру на AI-середовище з урахуванням вимог суверенітету даних. Також AWS інвестувала **$1 млрд** у створення Forward Deployed Engineering — команди інженерів, які вбудовуються в команди клієнтів для швидкого розгортання AI-рішень.

**Microsoft Azure (інновації останніх років):**

Azure розвиває **Microsoft Foundry** — платформу для управління AI-агентами з контролем витрат, токен-лімітами та ROI-трекінгом. **Azure Copilot Agents** інтегрують AI-агентів безпосередньо в Azure для міграції, оптимізації та управління навантаженнями. Microsoft активно впроваджує **мультимодельні стратегії**, дозволяючи комбінувати frontier, спеціалізовані та open-weight моделі. Azure OpenAI отримав моделі **GPT-4.1 (1M токенів)**, **o3-pro**, **codex-mini**, **Sora** для генерації відео, а також **Realtime API з WebRTC** для низьколатентної голосової взаємодії. Microsoft також демонструє використання AI-агентів для власного ланцюга поставок, скоротивши час виконання робочих процесів на **75%**.

**Google Cloud Platform (інновації останніх років):**

GCP оголосила про **епоху Agentic Enterprise** з запуском **Gemini Enterprise Agent Platform** — комплексної платформи для створення, масштабування та управління AI-агентами. Google представила **восьме покоління TPU** з двома архітектурами: **TPU 8t** для тренування (до 9 600 TPU, 2 ПБ пам'яті) та **TPU 8i** для інференсу (1 152 TPU, 3x більше SRAM для низької затримки). **Workspace Intelligence** — семантичний шар, що об'єднує дані з Gmail, Docs, Drive та Meet для створення розумного робочого середовища. **Gemini 3.5 Flash** та **Gemini Omni** — нові моделі для агентів та генерації відео. Google також активно впроваджує AI у кібербезпеку через інтеграцію **Wiz**.

#### Вибір платформи для розгортання хмарного серверу

**Мій вибір (світова платформа): Google Cloud Platform (GCP)**

Я обрав би GCP з таких причин:
- **Найкращі AI/ML-можливості:** TPU 8t/8i, Gemini Enterprise, Vertex AI — ідеально для сучасних AI-навантажень
- **Безкоштовний кредит $300** на 90 днів — достатньо для тестування та розгортання
- **Kubernetes (GKE)** — найзріліша реалізація, оскільки Google створила Kubernetes
- **Глобальна мережа** — один з найбільших backbone-провайдерів світу
- **Прозоре ціноутворення** — автоматичні знижки за тривале використання

**Мій вибір (українська платформа): GigaCloud**

Я обрав би GigaCloud з таких причин:
- **Лідер ринку** — найбільший дохід від хмарних послуг серед українських провайдерів
- **Найширша сертифікація** — ISO 27001/27701/27017/27018, PCI DSS, CSA STAR, VMware Sovereign Cloud
- **SLA 99.95%** з фінансовою відповідальністю
- **GPU Cloud для AI/ML** на базі VMware та NVIDIA — актуально для сучасних завдань
- **Географічний розподіл** — дата-центри в Києві, Львові та Варшаві, що забезпечує стійкість до регіональних збоїв
- **Найбільша партнерська мережа** — легше знайти підтримку та інтеграторів

**Обґрунтування вибору українського провайдера:** В умовах воєнного стану критично важливо мати провайдера, який забезпечує безперервність роботи, має дата-центри за межами України (Варшава) та відповідає міжнародним стандартам безпеки. GigaCloud найкраще відповідає цим вимогам.

## Висновки про виконання лабораторної роботи

У ході лабораторної роботи було досліджено можливості трьох найбільших світових хмарних провайдерів — AWS, Microsoft Azure та Google Cloud Platform. Встановлено, що всі три гравці активно розвивають напрямок **Agentic AI** (автономні AI-агенти), власні AI-чипи (Trainium3, TPU 8t/8i, Graviton5) та розширюють географію дата-центрів.

Порівняльний аналіз показав, що AWS має найширший вибір сервісів та найбільшу ринкову частку, Azure — найкращу інтеграцію з Microsoft-екосистемою, а GCP — найсильніші AI/ML-можливості завдяки власним TPU та Gemini Enterprise.

Дослідження українського ринку виявило, що **GigaCloud** є беззаперечним лідером за доходом, кількістю клієнтів та сертифікаціями. **De Novo** та **“Парковий”** складають конкуренцію, утворюючи разом з GigaCloud **Український Альянс Цифрового Суверенітету**. Українські провайдери пропонують ціни, подекуди **більш ніж удвічі нижчі** за гіперскейлерів, що робить їх привабливими для локального бізнесу.

Для розгортання власного хмарного серверу я обрав би **Google Cloud Platform** (світова платформа) через найкращі AI/ML-можливості та **GigaCloud** (українська платформа) через лідерство на ринку, широку сертифікацію та географічну стійкість.
